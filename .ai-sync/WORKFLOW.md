# Shared Workflow

This folder is the neutral handoff layer for ZCode, Codex, and Multica agents.

## Rules
1. Read STATUS.md before starting work.
2. If the project has AGENTS.md, CLAUDE.md, CODEX.md, or README.md instructions, follow them too.
3. Update STATUS.md when you claim work: set Current Focus, Next Step, and any Blockers.
4. Update STATUS.md again when you finish a meaningful chunk of work.
5. Keep notes short, factual, and tied to files or tasks.
6. Do not copy private chat history or app session data into this folder.

## Suggested Status Format
- Current Focus: what is being worked on now
- Next Step: the very next concrete action
- Blockers: missing info, failing environment, approvals needed
- Recent Decisions: small decision log with dates
- Notes For Next Agent: handoff notes for whoever continues next

## Scope Reminder
Use the same local project directory as the source of truth. App-specific caches are not the source of truth.
